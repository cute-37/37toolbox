## 四、自动更新（Codex，需要 GitHub Repo）

### 前置条件
需要一个 GitHub 仓库（公网可访问），并创建 Personal Access Token（`repo` scope）。

### Codex 需要做的
1. `npm install electron-updater --save-dev`
2. 确认 `electron-builder.yml` 的 `publish` 配置：
```yaml
publish:
  provider: github
  repo: 37toolbox
  owner: <你的GitHub用户名>
```
3. 在 `electron/main.ts` 中加入 autoUpdater 初始化：
```typescript
import { autoUpdater } from 'electron-updater';
autoUpdater.checkForUpdatesAndNotify();
```
4. `npm run package` 后手动上传 `release/*.exe` 到 GitHub Releases（打 tag `v0.3.0`）

### 提醒用户
> 自动更新功能需要你创建 GitHub 仓库。准备好后告诉 Codex，"按待办-v0.3.md §四 配置自动更新"。
