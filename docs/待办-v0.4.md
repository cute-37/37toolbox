## 二、自动更新（Codex，需要 GitHub Repo）

### 前置
用户创建 GitHub 仓库 + Personal Access Token

### 步骤
1. `npm install electron-updater --save-dev`
2. `electron-builder.yml` 加 `publish.provider: github`
3. `main.ts` 加 `autoUpdater.checkForUpdatesAndNotify()`
4. 手动上传 exe 到 GitHub Releases
