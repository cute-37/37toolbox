## 一、菜单栏问题分析（需求 #5 前置诊断）

当前窗口配置 `frame: false` + `titleBarStyle: 'hidden'`，去掉了原生标题栏。Electron 的 `Menu.setApplicationMenu()` 在 Windows 无边框窗口下，菜单**有定义但无处渲染**（原生菜单栏随 frame 一同消失）。这也是为什么菜单栏全部点不开。

**修复方案**: 双管齐下。

- **保留原生菜单**（main.ts 已有）：在 macOS 上原生菜单出现在系统菜单栏，快捷键（Ctrl+C / Ctrl+Q 等）跨平台生效。这部分不需要动。
- **新增渲染进程菜单栏组件**：在 TopBar 下方增加一个可点击的自定义菜单栏 React 组件。点击各项通过 IPC 调用主进程或触发浏览器 action。

这样 Windows 上点得动，macOS 上原生菜单也在，快捷键全局有效。

#### A2: 自定义分类（需求 #2）

这是最大的改动。当前 `ToolCategory` 是硬编码联合类型，需改为动态。

**Claude 做的**:
- `ToolCategory` 类型定义重写

```typescript
// 之前：硬编码联合类型
export type ToolCategory = 'daily' | 'image' | ...;

// 之后：保留预设 + 支持自定义
export const BUILTIN_CATEGORIES = ['daily','image','text','dev','download','custom'] as const;
export type BuiltinCategory = typeof BUILTIN_CATEGORIES[number];

// 用户分类存储结构
export interface CategoryDef {
  id: string;        // kebab-case，唯一，如 'my-tools'
  label: string;     // 显示名，如 '我的工具'
  order: number;     // 排序
  builtin: boolean;  // 内置分类不可删除
}

// 工具的 category 字段含义不变（存储分类 id），但取值范围从硬编码变为运行时检查
```

- `CATEGORY_LABELS` 改为从 `CategoryDef[]` 动态生成
- `CATEGORY_ORDER` 改为 `CategoryDef[].sort(by order)`
- `AppStore` 新增 `categories: CategoryDef[]` + CRUD actions

**Codex 做的**:
- `PluginManager` 中实现分类 CRUD（增删改查）
- 删除分类时，该分类下工具自动移到 `custom`
- 内置分类不可删除
- 持久化 key: `37toolbox:categories`

### 5.1 自定义分类类型（Claude 产出）

```typescript
// types.ts 中新增/修改

/** 分类定义 */
export interface CategoryDef {
  id: string;          // kebab-case 唯一 ID，内置分类用 'daily'/'image' 等
  label: string;       // 显示名
  order: number;       // 排序权重，数值越小越靠前
  builtin: boolean;    // 内置分类不可删除、不可改 id

/** 内置分类预设 */
export const BUILTIN_CATEGORIES: CategoryDef[] = [
  { id: 'daily',    label: '日常效率', order: 0, builtin: true },
  { id: 'image',    label: '图片处理', order: 1, builtin: true },
  { id: 'text',     label: '文本处理', order: 2, builtin: true },
  { id: 'dev',      label: '编码开发', order: 3, builtin: true },
  { id: 'download', label: '下载工具', order: 4, builtin: true },
  { id: 'custom',   label: '我的工具', order: 99, builtin: true },
];

// AppStore 新增
categories: CategoryDef[];   // 当前全部分类（内置 + 用户自定义）
addCategory: (label: string) => void;
updateCategory: (id: string, label: string) => void;
removeCategory: (id: string) => void;
reorderCategory: (id: string, newOrder: number) => void;
setToolCategory: (toolId: string, categoryId: string) => void;

// 删除 category 类型的联合类型约束，改为运行时校验
// ToolManifest.category 类型从 ToolCategory（联合类型）改为 string
```

### 5.2 右键菜单组件 Spec

```typescript
// ContextMenu 组件接口
interface ContextMenuItem {
  id: string;
  label: string;
  icon?: string;       // ToolIcon name
  disabled?: boolean;
  danger?: boolean;    // 红色文字（删除等危险操作）
  separator?: boolean; // 此项是分割线
  onClick: () => void;
}

interface ContextMenuProps {
  items: ContextMenuItem[];
  position: { x: number; y: number };
  onClose: () => void;
}

// 用法: 任何组件中
const [contextMenu, setContextMenu] = useState<{ x: number; y: number; items: ContextMenuItem[] } | null>(null);

<div onContextMenu={(e) => {
  e.preventDefault();
  setContextMenu({ x: e.clientX, y: e.clientY, items: getMenuItems() });
}}>
  ...
</div>

{contextMenu && <ContextMenu {...contextMenu} onClose={() => setContextMenu(null)} />}
```
