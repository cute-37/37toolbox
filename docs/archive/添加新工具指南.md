# 添加新工具指南

> 37工具箱的价值在于可以不断生长。本文档定义了一套标准流程，任何 AI（或人类开发者）都可以按照这个指南添加一个新工具。

---

## 一、什么时候需要新工具

满足以下全部条件就应该添加为一个独立工具：

1. 有一个独立、可描述的功能（不是已有工具的扩展）
2. 功能的输入和输出是明确的
3. 功能不需要修改内核代码

如果是给已有工具新增能力（比如给密码生成器加一个"生成多个密码"功能），应该修改那个工具的 engine.ts 和 Tool.tsx，而不是创建新工具。

---

## 二、工具目录结构

```
src/plugins/{tool-id}/
├── manifest.ts    # 工具元信息（必须）
├── engine.ts      # 纯逻辑函数（必须）
└── Tool.tsx       # React UI 组件（必须）
```

### 命名约束

- `{tool-id}` 必须用 kebab-case，全小写，不超过 30 字符。如 `password-gen`、`json-formatter`
- `{tool-id}` 不能与 `src/plugins/` 下已有目录重名
- 三个文件名固定不变：`manifest.ts`、`engine.ts`、`Tool.tsx`

---

## 三、按步骤来

### 步骤 1: 确定工具类型，更新类型定义

如果是全新的功能领域，可能需要新增 `ToolCategory` 值。当前分类：

| 值 | 含义 |
|----|------|
| `'daily'` | 日常效率 |
| `'image'` | 图片处理 |
| `'text'` | 文本处理 |
| `'dev'` | 编码开发 |
| `'download'` | 下载工具 |
| `'custom'` | 用户自定义 / 外部插件 |

**如果新增分类**：必须同步更新 `src/core/types.ts` 中的 `ToolCategory` 联合类型、`CATEGORY_LABELS` 映射、`CATEGORY_ORDER` 数组。这是唯一需要改内核文件的情况。

**如果不需要新分类**：跳过这一步，直接用已有分类。

### 步骤 2: 写 manifest.ts

```typescript
// @author: codex | phase: 4a | tool: {tool-id} | manifest
import type { ToolManifest } from '../../core/types';

export const manifest: ToolManifest = {
  id: '{tool-id}',              // kebab-case, 唯一
  name: '{工具名称}',            // 中文, 不超过 8 字
  description: '{一句话描述}',    // 不超过 20 字
  category: 'daily',            // 从已有分类中选一个
  version: '1.0.0',
  icon: '{lucide-icon-name}',   // 见 总控计划.md §10 附录 A
  tags: ['tag1', 'tag2'],       // 至少 2 个搜索关键词, 小写英文
  hasSettings: false,           // 有设置面板则 true
};
```

**注意事项**:
- `id` 一旦确定不要改，它被用作 localStorage key 和注册表 key
- `icon` 必须是 lucide-react 中存在的图标名
- `tags` 用于全局搜索，想好用户会用什么关键词搜索这个工具

### 步骤 3: 写 engine.ts

**职责**: 导出 manifest（步骤 2 中的同一个对象） + 所有纯函数。

**约束**:
- 函数为纯逻辑：不访问 DOM、不访问 localStorage、不调用 window API
- 所有函数必须有完整的 TypeScript 类型标注（参数类型 + 返回类型）
- 每个函数必须有 JSDoc 注释
- 引擎函数之间可以互相调用，但不得 import React 或任何组件

**模板**:

```typescript
// @author: codex | phase: 4a | tool: {tool-id} | engine
import type { ToolManifest } from '../../core/types';

// ====== Manifest（工具元信息，唯一源头） ======

export const manifest: ToolManifest = {
  id: '{tool-id}',
  name: '{工具名称}',
  description: '{一句话描述}',
  category: 'daily',
  version: '1.0.0',
  icon: '{icon-name}',
  tags: ['tag1', 'tag2'],
  hasSettings: false,
};

// ====== 引擎函数 ======

/**
 * {函数功能简述}
 * @param input - {参数说明}
 * @returns {返回值说明}
 */
export function myFunction(input: string): { ok: true; output: string } | { ok: false; error: string } {
  // 实现...
}
```

### 步骤 4: 写 Tool.tsx

**职责**: 接收 ToolProps，调用 engine 函数，渲染 UI。

**约束**:
- 默认导出 React 组件，类型为 `React.FC<ToolProps>`
- 从 `./engine` import 引擎函数（不要自己重写逻辑）
- 从 `../../components/shared` import 共享组件（Button、Input 等）
- 所有颜色使用 Tailwind class（如 `text-text-primary`、`bg-bg-secondary`），禁止硬编码色值
- 必须覆盖四种状态：空状态 / 正常态 / 错误态 / 处理中
- 文件不超过 300 行。超过则拆分子组件到 `./components/` 子目录
- 文件顶部标注 `// @author: frontend-ai | phase: 4b | tool: {tool-id} | ui`

**模板**:

```tsx
// @author: frontend-ai | phase: 4b | tool: {tool-id} | ui
import React, { useState, useCallback } from 'react';
import type { ToolProps } from '../../core/types';
import { manifest, myFunction } from './engine';
import { Button, Input, TextArea, EmptyState } from '../../components/shared';

const ToolName: React.FC<ToolProps> = ({ settings, onSettingsChange, onStatusChange, theme }) => {
  const [input, setInput] = useState('');
  const [output, setOutput] = useState<string | null>(null);
  const [error, setError] = useState<string | null>(null);

  const handleProcess = useCallback(() => {
    if (!input.trim()) return;
    setError(null);
    onStatusChange('running');
    const result = myFunction(input);
    if (result.ok) {
      setOutput(result.output);
      onStatusChange('success');
    } else {
      setError(result.error);
      onStatusChange('error', result.error);
    }
  }, [input, onStatusChange]);

  // 空状态
  if (!input && !output) {
    return <EmptyState icon={manifest.icon} title={manifest.name} description={manifest.description} />;
  }

  return (
    <div className="flex flex-col gap-4 h-full">
      {/* 输入区 */}
      <Input value={input} onChange={setInput} placeholder="请输入..." />

      {/* 操作按钮 */}
      <Button variant="primary" onClick={handleProcess}>处理</Button>

      {/* 错误态 */}
      {error && (
        <div className="text-status-error text-sm border border-status-error/30 rounded-md p-3 bg-status-error/10">
          {error}
        </div>
      )}

      {/* 输出区 */}
      {output && (
        <TextArea value={output} readOnly className="font-mono" />
      )}
    </div>
  );
};

export default ToolName;
```

### 步骤 5: 注册到 pluginRegistry

在 `src/core/pluginRegistry.ts` 中添加这个工具的 lazy loader：

```typescript
{
  id: '{tool-id}',
  loader: () => import('../plugins/{tool-id}/Tool'),
  builtin: true,
}
```

**注意**: 如果这个工具是新分类下的第一个工具，还需要在 pluginRegistry 的 `getCategoryPlugins()` 或其他分类相关函数中处理新分类。

### 步骤 6: 验证清单

新工具完成后，逐项检查：

- [ ] `manifest.ts` 中所有字段已填写，id 唯一且为 kebab-case
- [ ] `engine.ts` 中函数签名完整（参数类型 + 返回类型 + JSDoc）
- [ ] `engine.ts` 中函数为纯逻辑，无 DOM/React 依赖
- [ ] `Tool.tsx` 从 `./engine` import 引擎函数（未自己重写逻辑）
- [ ] `Tool.tsx` 使用 Tailwind class 引用颜色（未硬编码色值）
- [ ] `Tool.tsx` 覆盖了空状态 / 正常态 / 错误态 / 处理中
- [ ] `Tool.tsx` 文件不超过 300 行
- [ ] `pluginRegistry.ts` 中已注册
- [ ] `npm run dev` 中能正常切换到新工具，不报错
- [ ] 搜索关键词能找到这个工具
- [ ] 文件顶部有 @author 标注

## 四、完整示例：一个最简工具

以"字数统计"工具为例，完整的三个文件：

### manifest.ts

```typescript
// @author: codex | phase: 4a | tool: word-count | manifest
import type { ToolManifest } from '../../core/types';

export const manifest: ToolManifest = {
  id: 'word-count',
  name: '字数统计',
  description: '统计文本字数、行数、字符数',
  category: 'text',
  version: '1.0.0',
  icon: 'type',
  tags: ['word', 'count', 'character', 'line'],
  hasSettings: false,
};
```

### engine.ts

```typescript
// @author: codex | phase: 4a | tool: word-count | engine
import type { ToolManifest } from '../../core/types';

export const manifest: ToolManifest = {
  id: 'word-count',
  name: '字数统计',
  description: '统计文本字数、行数、字符数',
  category: 'text',
  version: '1.0.0',
  icon: 'type',
  tags: ['word', 'count', 'character', 'line'],
  hasSettings: false,
};

export interface WordCountStats {
  characters: number;     // 总字符数（含空格）
  charactersNoSpaces: number; // 字符数（不含空格）
  words: number;          // 英文单词数
  lines: number;          // 行数
  paragraphs: number;     // 段落数
  bytes: number;          // UTF-8 字节数
}

/**
 * 统计文本的各项指标
 * @param text - 输入文本
 * @returns 统计结果
 */
export function countWords(text: string): WordCountStats {
  const characters = text.length;
  const charactersNoSpaces = text.replace(/\s/g, '').length;
  const words = text.trim() ? text.trim().split(/\s+/).length : 0;
  const lines = text ? text.split('\n').length : 0;
  const paragraphs = text.trim() ? text.trim().split(/\n\s*\n/).filter(Boolean).length : 0;
  const bytes = new TextEncoder().encode(text).length;

  return { characters, charactersNoSpaces, words, lines, paragraphs, bytes };
}
```

### Tool.tsx

```tsx
// @author: frontend-ai | phase: 4b | tool: word-count | ui
import React, { useState, useEffect, useCallback } from 'react';
import type { ToolProps } from '../../core/types';
import { manifest, countWords, type WordCountStats } from './engine';
import { TextArea, EmptyState } from '../../components/shared';

const WordCountTool: React.FC<ToolProps> = ({ onStatusChange }) => {
  const [text, setText] = useState('');
  const [stats, setStats] = useState<WordCountStats | null>(null);

  useEffect(() => {
    if (!text) {
      setStats(null);
      onStatusChange('idle');
      return;
    }
    try {
      setStats(countWords(text));
      onStatusChange('success');
    } catch {
      onStatusChange('error', '统计失败');
    }
  }, [text, onStatusChange]);

  if (!text) {
    return (
      <EmptyState
        icon="type"
        title="字数统计"
        description="输入文本，实时查看字数、行数、字符数"
      />
    );
  }

  return (
    <div className="flex flex-col gap-4 h-full">
      <TextArea
        value={text}
        onChange={setText}
        placeholder="输入或粘贴文本..."
        className="flex-1 min-h-[200px] font-mono"
      />

      {stats && (
        <div className="grid grid-cols-3 gap-3">
          <StatCard label="总字符数" value={stats.characters} />
          <StatCard label="字符数(不含空格)" value={stats.charactersNoSpaces} />
          <StatCard label="单词数" value={stats.words} />
          <StatCard label="行数" value={stats.lines} />
          <StatCard label="段落数" value={stats.paragraphs} />
          <StatCard label="字节数(UTF-8)" value={stats.bytes} />
        </div>
      )}
    </div>
  );
};

// 统计卡片子组件
const StatCard: React.FC<{ label: string; value: number }> = ({ label, value }) => (
  <div className="bg-bg-secondary border border-border rounded-md p-3 text-center">
    <div className="text-lg font-semibold text-text-primary">{value.toLocaleString()}</div>
    <div className="text-xs text-text-secondary mt-1">{label}</div>
  </div>
);

export default WordCountTool;
```

## 五、外部插件（用户自定义）

用户也可以在 `~/37工具箱/plugins/{tool-id}/` 下放置插件。目录只需要一个 `index.tsx` 文件：

```
~/37工具箱/plugins/{tool-id}/
└── index.tsx    # 同时导出 manifest 和 default component
```

```tsx
import React from 'react';
import type { ToolManifest, ToolProps } from 'some-type-source'; // 我们会提供一个 npm 包

export const manifest: ToolManifest = {
  id: 'my-custom-tool',
  name: '我的工具',
  description: '自定义工具',
  category: 'custom',
  version: '1.0.0',
  icon: 'zap',
  tags: ['custom'],
  hasSettings: false,
};

const MyTool: React.FC<ToolProps> = ({ onStatusChange }) => {
  // ...
};

export default MyTool;
```

PluginManager 会自动扫描这个目录（需要在 Phase 3 中实现），外部插件加载到 `custom` 分类下。

## 六、快速对照表

| 你做的是什么 | 对应文件 | 谁写 | 关键约束 |
|-------------|---------|------|---------|
| 工具元信息 | manifest.ts | Codex | id 唯一，icon 有效 |
| 工具逻辑 | engine.ts | Codex | 纯函数，完整类型，JSDoc |
| 工具界面 | Tool.tsx | 前端 AI | 从 engine import，四种状态，Tailwind class |
| 注册工具 | pluginRegistry.ts | Codex | 添加 lazy loader |
| Spec 更新 | 总控计划.md | Claude | 同步更新 §6 + §10 附录 |
| 规范更新 | 开发规范.md | Claude | 同步更新对应章节 + 修订记录 |
