# Pixiv 下载器 — 工具封装说明

## 做了什么

将 `D:\Coding\projects\pixiv_downloader` 的 Python CLI 项目封装为 37 工具箱的插件工具。分为四层：

| 层 | 文件 | 作用 |
|----|------|------|
| Python 桥接 | `bridge.py` | 接收 JSON 命令，调用 processor.py，输出 JSON 行到 stdout |
| Electron IPC | `electron/ipc/pythonHandlers.ts` | spawn Python 进程，转发 stdin/stdout |
| TypeScript 引擎 | `engine.ts` | 通过 `window.toolbox.python.*` 调用 Python 桥接 |
| React UI | `Tool.tsx` | 三大 Tab：操作 / 账号 / 设置 |

## 你现在需要做的事（按顺序）

### 1. 复制 Python 项目

把 `D:\Coding\projects\pixiv_downloader` 中的所有 `.py` 文件和 `db/` `avatars/` 目录复制到：

```
D:\Coding\projects\37工具箱\工具开发\pixiv-downloader\
```

**注意**: 不要覆盖我已经创建的 `bridge.py`。

需要复制的核心文件：
```
main.py        processor.py    pixiv_client.py
config.py      storage.py      db_manager_v2.py
token_manager.py  interrupt.py  download_ugoira.py
download_novel.py  add_illust.py  check_db.py
tests/  (可选)
```

### 2. 确认 Python 环境

在终端中确认 conda 环境 `pix` 可用：
```bash
conda activate pix
python --version
pip list | grep pixivpy3
```

如果没有，安装依赖：
```bash
conda create -n pix python=3.10 -y
conda activate pix
pip install pixivpy3 requests tqdm pysmb pillow
```

### 3. 测试 bridge.py 独立运行

```bash
cd D:\Coding\projects\37工具箱\工具开发\pixiv-downloader
conda activate pix
echo {"action":"status"} | python bridge.py --pipe
```

应该看到类似输出：
```json
{"type": "ready"}
{"type": "status", "ok": true, "data": {...}}
```

### 4. 测试 Python 路径

如果上一步正常，确认 `D:\Coding\miniconda3\envs\pix\python.exe` 存在。如果 conda 装在其他位置（如 `anaconda3`），需要修改 `electron/ipc/pythonHandlers.ts` 中的 `getPythonPath()` 函数。

### 5. 启动工具箱测试

```bash
cd D:\Coding\projects\37工具箱
npm run dev
```

打开后 Pixiv 工具会在仪表盘显示（当前设置为默认隐藏，需要在设置中手动开启）。

## Tool.tsx 功能说明

**操作 Tab**:
- 全量/增量同步、仅下载、同步+下载
- 实时进度日志、手动停止

**账号 Tab**:
- 查看所有已保存账号、设为主账号、删除
- 添加新账号（PKCE 授权流程：浏览器登录 → 粘贴回调 URL → 获取 token）
- 测试全部 token 可用性

**设置 Tab**:
- 存储（本地文件系统 / SMB-CIFS 网络共享连接信息）
- 线程数（下载/同步/主账号/备份）
- Ugoira 格式 (GIF/APNG/WebP)
- 风控保护、自动降速、失败率阈值
- 保存后同步到 Python settings.json
